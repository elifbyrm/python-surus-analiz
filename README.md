# Vehicle Movement Analyzer

A Python mini project developed to analyze vehicle movement data using object-oriented programming.

## Features
- Total distance calculation
- Maximum speed calculation
- Average speed calculation
- Number of stops
- Speed limit violation detection
- Route visualization using Matplotlib

## Technologies
- Python
- CSV
- Matplotlib
- Object-Oriented Programming

## How to Run

Install Matplotlib:

```bash
pip install matplotlib
```

Run the project:

```bash
python surus.py
```
